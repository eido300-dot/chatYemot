# חיבור ימות, פוש ותמלול

אין לשמור מפתחות, PIN או סיסמאות ב־Git או לשלוח אותם בצ׳אט. `.env` מוגן בהרשאות 0600 ומוחרג מ־Git. בייצור יש להשתמש בקובץ environment מוגן או מנהל סודות.

## ימות המשיח

1. קבעו `YEMOT_TOKEN` כמפתח API קבוע לחשבון, `YEMOT_DID` כמספר המערכת, `YEMOT_WEBHOOK_SECRET` כסוד אקראי של לפחות 32 תווים.
2. הקצו תיקיית מדיה ייעודית קיימת כגון `/9` ב־`YEMOT_MEDIA_FOLDER`. **חסמו אותה לחיוג ישיר**; אחרת הגנת ה־PIN של endpoint אינה מגנה על קובצי הקו. וודאו הרשאות כתיבה של מפתח ה־API.
3. בשלוחת הכניסה הגדירו `type=api`, `api_link=https://DOMAIN/ivr/SECRET/`, `api_url_post=yes`.
4. מנעו רישום נתיב ה־webhook המלא בכל שכבות Nginx/Apache, CDN, WAF ומערכות ניטור. הסוד אינו תחליף ל־HTTPS. השרת בודק גם ApiDID; מספר מזוהה לבדו אינו הזדהות.
5. הגדירו למשתמש מספר מזוהה ו־PIN נפרד. המערכת אינה מקריאה את הקוד בחזרה. יש הגבלה לשלושה ניסיונות בכל תפריט והגבלה מתמשכת על ניסיונות הזדהות.
6. הפעילו `YEMOT_ENABLED=true` והפעילו מחדש את התהליך היחיד. בדקו שיחה חיה והודעות בשני הכיוונים לפני צינתוק.

טקסט מהאתר עולה באמצעות `UploadTextFile` לנתיב `ivr2:/FOLDER/IDvVERSION.tts`, שמע באמצעות `UploadFile`. לפני סימון כזמין מתבצעת `CheckIfFileExists` (נדרשת תשובת `fileExists` חיובית). נתיבי ההשמעה ללא סיומת. API ההורדה מחזיר שמע בינארי; ההורדה מוגבלת בגודל ומומרת מקומית. צריך לאמת בפועל את התנהגות TTS, נתיבי ההקלטה ושדה קיום הקובץ בחשבון המשתמש; הם לא נבדקו מול ספק חי.

## צינתוק

`TZINTUK_ENABLED=true` ו־`YEMOT_TZINTUK_LIST` כמזהה רשימת צינתוקים חינמיים קיימת. משתמשים **רק** ב־`RunTzintuk` עם `phones=tzl:LIST_ID`, בלי מספרים ישירים ובלי קמפיין בתשלום. אין להניח שהחשבון זכאי או שהפעולה חינמית עד לאימות עם ימות. אין fallback בתשלום.

הצינתוק מתוזמן רק אחרי פרסום ההודעה לקו. עריכות אינן יוצרות צינתוק נוסף. לפני הפעלה ראשונה יש לבדוק משימות pending והיסטוריה עם מנהל הקבוצה.

## Web Push

`npm run keys` מפיק זוג מפתחות VAPID; להריץ במסוף פרטי, לשמור ערכים בצורה מאובטחת ולשמור על המפתח הפרטי קבוע. הגדירו `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` עם כתובת קשר אמיתית. המשתמש מפעיל התראות באתר ומאשר בדפדפן. מאושרים רק יעדי FCM, Mozilla ו־Apple מוכרים. כברירת מחדל ההתראה מציגה את שם השולח ואת תוכן ההודעה (או התמלול של הודעה קולית) ומאפשרת תגובה ישירות מההתראה: באנדרואיד/Chrome שדה תגובה בתוך ההתראה, ובמכשירים אחרים כפתור "השב" שפותח את האתר על ההודעה. ההתראה לא נשלחת לשולח עצמו. להתראה כללית בלי תוכן במסך הנעילה הגדירו `PUSH_SHOW_CONTENT=false`.

ב־iOS ייתכן שנדרשת הוספה למסך הבית. יש לבדוק מסירה למכשיר אמיתי. אין שליחת פוש מהבדיקות לספק חי.

## תמלול אופציונלי

לאחר הסכמת הקבוצה להעברת ההקלטות ל־OpenAI, הגדירו `TRANSCRIPTION_ENABLED=true` ו־`OPENAI_API_KEY`. נעשה שימוש ב־`gpt-4o-mini-transcribe` עם `language=he`. הפעולה עשויה להיות בתשלום. התמלול אינו דורס תיקון ידני. בלי ספק ניתן להוסיף ולתקן תמלול באתר.

## יעדי רשת

התקנת npm דורשת registry.npmjs.org. Docker דורש registry-1.docker.io, auth.docker.io ואת CDN ההפצה. בזמן ריצה: www.call2all.co.il עבור ימות; api.openai.com רק לתמלול מופעל; fcm.googleapis.com, updates.push.services.mozilla.com ו־web.push.apple.com לפוש. יש להוסיף יעדים נדרשים להגדרות הסביבה בעת חיבור השירותים; כעת אין credentials חיים ואין הרחבת רשת לאינטגרציות.
