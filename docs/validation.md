# אימות מקומי — 16.11.2026

הקוד נבנה מחדש בסביבה הנוכחית; תוצאות המסירה מהסשן הקודם אינן משמשות הוכחה לגרסה זו.

עברו:

- התקנה חוזרת עם `npm ci --cache /workspace/.npm --no-fund --no-audit` מתוך lockfile.
- הפעלה חוזרת של מסדי הפיתוח והבדיקות באמצעות `scripts/dev-db.sh`, בלי מחיקת קונטיינרים או volumes, ויצירת הסכימה החוזרת עם `npm run db:migrate`.
- 11 בדיקות Node מול MariaDB 11.4 אמיתי: session, Origin, CSRF, הודעות ותגובות, עריכות והרשאות, גרסאות והתנגשות, חיפוש, המרת WAV עם FFmpeg והאזנה מאומתת, תמלול ידני לפני סנכרון, תור סנכרון/צינתוק עם ספק מדומה, אי־חזרה על צינתוק עמום, הגבלת ניסיונות IVR, רצפי HTTP אמיתיים של yemot-router2 להזדהות ולהקלטה, ייבוא הקלטה, חסימת יעדי פוש שרירותיים, סימון כנקרא ויציאה.
- Chromium אמיתי: כניסה, טקסט, תגובה, עריכה, העלאת שמע, עריכת תמלול, XSS מוצג כטקסט, חיפוש, תצוגת מובייל ללא גלילה אופקית, סימון כנקרא ויציאה. נוצרו צילומים ב־screenshots ונבדקו חזותית.
- הפעלת `src/server.js` המלא עם worker, תשובת `/health` תקינה מול מסד והפסקה עם SIGTERM בקוד יציאה 0.
- קובץ `.env` בהרשאות 0600 ומוחרג מ־Git, כמו גם נתוני המדיה וה־node_modules.

תלויות: npm audit דיווח על 3 ממצאים בדרגת low בשרשרת כלי Rollup של yemot-router2, ללא תיקון מוצע; אין ממצאי moderate/high/critical בריצה זו.

לא נבדקו: שיחה דרך חשבון ימות חי, השמעת TTS במערכת בפועל, זכאות או מחיר צינתוק, מסירת פוש למכשיר, תמלול דרך OpenAI, פריסה בשרת Ubuntu של המשתמש, תצורות Nginx/systemd בייצור ושחזור בסביבת ענן חדשה. אין credentials חיים. מסד הפיתוח נפרד ממסד הבדיקות ואינו מכיל משתמש כניסה מובנה.

נשמרה טיוטת install_script/start_skill להגדרות הענן; פרסום הסביבה הוא פעולה נפרדת בממשק. מצב השמירה ב־GitHub נבדק בנפרד באמצעות Git. ארכיון המקור אינו כולל `.env`, נתוני מסד, מדיה או תלויות מותקנות.
