# סקילים לפיתוח

עותקים מקומיים מתוך [mattpocock/skills](https://github.com/mattpocock/skills) נמצאים ב־`.agents/skills/`, המיקום המקובל לסקילים של Codex בפרויקט. הסקילים אינם תלות של האפליקציה ואינם נשלחים למשתמשי האתר.

- `tdd`: פיתוח התנהגות אחת בכל פעם, עם בדיקה נכשלת לפני המימוש ובדיקות דרך ממשקים ציבוריים.
- `diagnosing-bugs`: שחזור, אבחון ואימות תיקון של תקלות.
- `codebase-design`: תכנון מודולים עם ממשק קטן שמסתיר מורכבות.
- `code-review`: סקירת קוד מול דרישות ותקני הפרויקט.

יש לקרוא את קובץ `SKILL.md` הרלוונטי לפני השימוש ולפעול לפי ההקשר והוראות המשתמש. לדוגמה: “השתמש ב־tdd לתיקון התקלה” או “בצע code-review לשינוי”. סקילים שמשתמשים בתתי־סוכנים דורשים תמיכה בכך בסביבה. לפני בדיקות חדשות יש לפעול לפי הנחיות tdd להסכמה על הממשקים שייבדקו. הוראות הסקילים אינן אישור אוטומטי לשינוי נתונים, לפריסה או לפעולות חיצוניות.

הגרסה המקורית וחתימות הקבצים מתועדות ב־`.agents/mattpocock-skills.json`; הרישיון נשמר ב־`.agents/mattpocock-skills.LICENSE`. כל קובצי העזר הועתקו ללא שינוי. אין עדכונים אוטומטיים: יש לבדוק את השינויים במקור לפני החלפת העותקים.

התקנה זו כוללת את ארבעת הסקילים שלעיל בלבד. לא הוגדרו מנהל משימות, תוויות triage או plugin גלובלי, ולא הותקנו סקילים ניסיוניים. ייתכן שיידרש סשן חדש כדי שהסקילים יופיעו בקטלוג הממשק; ניתן לקרוא ולהשתמש בקבצים ישירות כבר בסביבה הנוכחית.
