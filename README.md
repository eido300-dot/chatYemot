# ChatYemot

צ׳אט לקבוצה סגורה אחת, בעברית וב־RTL, עם ממשק אתר וקו טלפוני בימות המשיח.

Node.js ≥22, Express, MariaDB ≥10.6 (נבדק 11.4), FFmpeg. אין שלב build, Redis או שירות תמלול חובה. יש להריץ **תהליך Node אחד בלבד**: שיחות IVR מוחזקות בזיכרון. תור המשימות נשמר במסד.

## פיתוח מקומי

```sh
npm ci --cache /workspace/.npm
./scripts/dev-db.sh
npm run db:migrate
npm start
```

הסקריפט יוצר `.env` פרטי אם חסר, וסביבת MariaDB עם נתונים מתמשכים ב־Docker volumes: `chatyemot-db` בפורט 3306 ו־`chatyemot-test-db` בפורט 3307. הוא מפעיל מחדש קונטיינרים קיימים ואינו מוחק נתונים. מיועד לסביבת הפיתוח `/workspace/chatYemot` בלבד. שינויים בסיסמה של קונטיינר קיים אינם משנים את סיסמת המסד — אין למחוק volume כדי לפתור חוסר התאמה.

יצירת משתמשים מראש (אין הרשמה פתוחה): להזין `NEW_USER_PASSWORD` ו־`NEW_USER_PIN` באמצעות מנגנון סודות או read פרטי, ולא בשורת פקודה הנשמרת בהיסטוריה. הסיסמה לפחות 12 תווים, PIN נפרד של 6–12 ספרות.

```sh
npm run user -- username 'שם מלא' 0501234567 admin
```

השמטת `admin` יוצרת חבר רגיל. מספר טלפון הוא ייחודי. אפשר להשמיט מספר ו־PIN למשתמש אתר בלבד. שמות וסיסמאות אינם מובנים בקוד. המשתנים נדרשים רק בזמן יצירת משתמש.

## בדיקות

```sh
TEST_DB_NAME=chatyemot_test npm test
TEST_DB_NAME=chatyemot_test npm run test:browser
```

בדיקות השרת **מוחקות את תוכן מסד הבדיקות** לפני הריצה. יש להשתמש רק במסד ייעודי ששמו מסתיים ב־`_test`, בשרת מקומי. `TEST_DB_PORT` ברירת מחדל 3307. בדיקות הדפדפן מפעילות שרת זמני מול אותו מסד, מוסיפות נתוני בדיקה ומפיקות צילומים ב־`docs/screenshots`. אין להריץ את שתי החבילות במקביל. `CHROMIUM_PATH` מאפשר שינוי מנתיב ברירת המחדל `/usr/bin/chromium`.

הבדיקות כוללות MariaDB ו־FFmpeg אמיתיים, HTTP של האתר ושל yemot-router2, הרשאות, גרסאות, תגובות, חיפוש, הקלטות ותור משימות. חיבורי ימות ופוש מדומים בבדיקות הרקע. הן אינן מוכיחות תקינות בחשבון ימות חי או מסירת התראה למכשיר.

## מה כלול

- כניסה, session מאובטח ו־CSRF, קבוצה אחת לכל החברים הפעילים.
- טקסט, העלאת שמע והקלטת דפדפן, תגובות עם ציטוט, חיפוש, הודעות קודמות וסימון כנקרא.
- עריכת הודעות ותמלול עם בדיקת גרסה ושמירת היסטוריה; עריכה אינה שולחת התראה נוספת.
- הרשאות בעל הודעה/מנהל, נגן שמע מאומת ותצוגת תמלול.
- מסך מצב למנהל; יצירת משתמשים בכלי CLI.
- קו עם מספר משויך + PIN, הודעות חדשות/כולן, הקלטה ותגובות. מעקב קריאה בקו נפרד מהאתר.
- משימות `sync`, `import`, `push`, `tzintuk`, `transcribe`, עם נעילות ו־retry מוגבל.
- רענון כל 10 שניות. PWA בסיסי ללא אחסון מקומי של תוכן פרטי.

## מגבלות ותפעול

כל חבר פעיל יכול לקרוא את כל הקבוצה. אין הצפנה מקצה לקצה. המנהל יוצר משתמשים; ניהול/השבתה דרך SQL או כלי תפעול, ללא מסך CRUD. אין מחיקת הודעות או מדיה אוטומטית. הקלטות מוגבלות ל־12MB, המרה ל־WAV מונו 8kHz ועד 180 שניות. הקלטת דפדפן ופוש דורשים HTTPS (או localhost לפיתוח). אין מטמון offline של תוכן.

פוש, צינתוק, סנכרון ותמלול כבויים בהיעדר הגדרה. המשימות נשמרות וממתינות; לפני הפעלת אינטגרציה יש לעבור על התור כדי שלא להפעיל התראות על היסטוריה. יש לגבות את המסד ואת `DATA_DIR` יחד. גיבוי checkout אינו גיבוי של Docker volumes.

אם תוצאת משלוח פוש/צינתוק עמומה, המשימה מסומנת `uncertain` ולא נשלחת שוב אוטומטית. אחרי קריסה משימות משלוח שהיו `running` מסומנות כך גם כן. יש לבדוק מול הספק לפני כל ניסיון ידני. אין exactly-once מול ספק חיצוני שאינו מספק idempotency.

`npm audit` בעת ההקמה דיווח על 3 ממצאי low בשרשרת כלי Rollup של yemot-router2 (deepmerge). אין תיקון זמין דרך audit. כלי הבנייה הזה אינו מיובא במסלול ESM של האפליקציה. אין להציג את התלויות כנקיות מממצאים.
